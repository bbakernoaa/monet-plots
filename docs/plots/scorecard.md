# Scorecard

The `ScorecardPlot` provides a grid-based summary of model performance across multiple metrics and models.

## Overview

Scorecards are high-level summary tools used to compare different model versions or configurations. They often use color coding (e.g., green for improvement, red for degradation) to provide a quick assessment of performance changes.
